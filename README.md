# 📊 Análise de People Analytics

Projeto de análise de dados de colaboradores utilizando **Python, Pandas, SQL e Power BI**, desenvolvido para demonstrar competências em análise de dados, indicadores de negócio e visualização de informações.

## 🎯 Objetivo

Analisar dados fictícios de colaboradores para identificar padrões relacionados a:

- Perfil profissional
- Remuneração
- Desempenho
- Satisfação
- Tempo de empresa
- Desligamentos
- Distribuição por departamento e cargo

## Principais indicadores

- Total de colaboradores
- Salário médio
- Tempo médio de empresa
- Taxa de desligamento
- Média de desempenho
- Satisfação média
- Colaboradores por departamento
- Desligamentos por departamento
- Salário médio por departamento
- Desempenho médio por departamento

## 📊 Dashboard

Dashboard desenvolvido no Power BI para acompanhamento dos principais indicadores de People Analytics.

## Análises realizadas

O projeto permite responder perguntas como:

1. Quantos colaboradores existem na empresa?
2. Qual é o salário médio?
3. Qual departamento possui mais colaboradores?
4. Qual departamento apresenta maior salário médio?
5. Qual é a taxa de desligamento?
6. Quais departamentos apresentam mais desligamentos?
7. Qual é a média de desempenho dos colaboradores?
8. Qual é o nível médio de satisfação?
9. Como os indicadores variam entre os departamentos?
10. Como os resultados podem apoiar decisões relacionadas à gestão de pessoas?

## Contexto profissional

O projeto simula um cenário empresarial em que dados de colaboradores são utilizados para apoiar análises relacionadas à gestão de pessoas e tomada de decisão.

A aplicação de análise de dados em People Analytics pode auxiliar na identificação de padrões de remuneração, desempenho, satisfação e desligamentos.

## Dados

A base contém **200 registros fictícios de colaboradores** e foi criada exclusivamente para fins educacionais e demonstração de competências em análise de dados.

Os dados não representam uma empresa real.
