# Análise de People Analytics

## Objetivo

Analisar dados fictícios de colaboradores para identificar padrões relacionados a perfil profissional, remuneração, desempenho, satisfação e desligamentos.

## Indicadores analisados

- Total de colaboradores
- Salário médio
- Tempo médio de empresa
- Taxa de desligamento
- Avaliação média de desempenho
- Satisfação média

## Análises realizadas

O projeto permite analisar:

- Distribuição de colaboradores por departamento
- Salário médio por departamento
- Salário médio por cargo
- Desempenho médio por departamento
- Taxa de desligamento
- Relação entre satisfação e desligamento
- Distribuição entre colaboradores ativos e desligados

## Perguntas de negócio

1. Quantos colaboradores a empresa possui?
2. Qual é o salário médio?
3. Qual departamento possui maior número de colaboradores?
4. Qual departamento apresenta maior salário médio?
5. Qual é a taxa de desligamento?
6. Quais departamentos apresentam mais desligamentos?
7. Qual é a média de desempenho dos colaboradores?
8. Qual é o nível médio de satisfação?
9. Existe relação entre satisfação e desligamento?
10. Como os indicadores variam entre os departamentos?

## Tecnologias utilizadas

- Python
- Pandas
- SQL
- Power BI
- GitHub

## Dados

A base contém 200 colaboradores fictícios e foi criada exclusivamente para fins educacionais e de demonstração de competências em análise de dados.

## Fluxo

Dados → Python → SQL → Indicadores → Power BI → Dashboard → Análise
